# Verification Checklist

## Before Using an AI Assistant

- Remove names, email addresses, device identifiers, IP addresses, tokens, and internal URLs.
- Confirm the organization permits the selected tool and data type.
- Preserve the exact technical meaning after sanitization.

## Before Running a Suggested Command

- Read the full command and identify every target.
- Check syntax against authoritative documentation.
- Confirm the command applies to the installed operating-system or software version.
- Prefer a read-only mode, dry run, or `WhatIf` option.
- Confirm backup, rollback, and required approval.

## Before Closing the Ticket

- Reproduce the original workflow successfully.
- Restart or retest where appropriate.
- Confirm no unrelated function regressed.
- Record the actual root cause instead of the initial AI suggestion.
- Add useful findings to a knowledge base without sensitive data.
